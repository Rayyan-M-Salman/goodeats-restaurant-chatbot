# Good Eats Restaurant Chatbot
An AI chatbot for a fictional restaurant, showcasing a basic application of an LLM.

# Download all requirements: 
Python Libraries: json, flask, requests, pathlib.
AI model: Qwen2.5:7b , ollama

# Usage:
-Run: 'restaurant-chatbot.py' and go to 'http://127.0.0.1:5000'
-Ask the chatbot any question about the restaurant.

# Config
You can edit the 'restaurant_data.json' file to change information about the restaurant.
You can change restaurant name, description, phone number, currency, opening hours, address, menu items, prices, ingredients, allergens, and any dietary tags.
To edit the website's UI, edit the HTML file under templates, or create a new one and apply that one in the python app.
